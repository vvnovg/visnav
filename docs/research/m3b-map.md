# M3b: офлайн-карта и навигационный экран

## Что нужно (делает владелец)
- Java 21 для planetiler: `brew install openjdk@21`.
- planetiler: `curl -L -o data/osm/planetiler.jar https://github.com/onthegomap/planetiler/releases/latest/download/planetiler.jar`.
- Шрифты: `curl -L -o data/osm/noto-sans.zip https://github.com/openmaptiles/fonts/releases/download/v2.0/noto-sans.zip` (~60 МБ, OFL/Apache).
- Выгрузка OSM — как в M2b (`data/osm/moscow.osm.pbf`).
- Граф дорог и точка назначения — как в M3a (`docs/research/m3a-route.md`); без них экран показывает карту и позицию, но не маршрут.

## 1. Тайлы коридора
```bash
cd /Users/vvnovg/navigator/research/vpr_bench
J21="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home/bin/java"
# границы — bbox коридора с запасом; planetiler сам скачает воду и границы (--download)
$J21 -Xmx4g -jar data/osm/planetiler.jar --download --osm-path=data/osm/moscow.osm.pbf \
  --bounds=37.30,55.55,37.95,55.95 --maxzoom=14 --output=data/m3b/moscow.mbtiles
S=data/m1/logs/session-<ms>-gps
uv run vpr-m3 pack-map --mbtiles data/m3b/moscow.mbtiles --fonts-zip data/osm/noto-sans.zip \
  --log $S.jsonl --buffer-m 500 --out data/m3b/map
```
`pack-map`:
- проверяет тайлы: они должны быть векторными и содержать слои OpenMapTiles;
- оставляет тайлы масштаба ниже 10 целиком, а тайлы масштаба 10 и выше — только в коридоре ±500 м;
- кладёт глифы Noto Sans (латиница и кириллица) и `map.json` с границами коридора и атрибуцией;
- печатает размер на 100 км (цель NFR-8 — ≤ 50 МБ на 100 км вместе с эталонами).

Треков может быть несколько: `--log` и `--gpx` повторяются. Обрезка временно требует места примерно втрое больше исходного `.mbtiles`.

## 2. Телефон
```bash
adb push data/m3b/map /sdcard/Android/data/io.visnav.app/files/refpack/
```
В итоге на телефоне получается `files/refpack/map/` с файлами `corridor.mbtiles`, `fonts/…` и `map.json`. Если карту положили, когда приложение уже открыто, нужно переключить вкладку, и карта загрузится.

- **Вкладка «Навигация»:**
  - слева — стрелка следующего манёвра, расстояние до него («Сейчас» ближе 30 м), улица, режим позиционирования с точностью, остаток пути и времени, кнопки «Старт/Стоп» и «В центр»;
  - справа — карта: маршрут, точки манёвров, маркер и круг неопределённости в цвете режима, стрелка курса при скорости ≥ 3 м/с;
  - атрибуция «© OpenMapTiles © участники OpenStreetMap» видна постоянно.
- **Камера:**
  - следует курсом вверх; курс обновляется при скорости ≥ 3 м/с, на стоянке сохраняется последний (до первого движения — север вверх);
  - масштаб зависит от скорости: 17 → 16 → 15,5 → 15;
  - после жеста пользователя карта свободна 10 с или до кнопки «В центр».
- **Вкладка «Отладка»** — прежний экран M1. Обе вкладки работают с одной и той же сессией записи.
- **День и ночь** — по теме системы; при смене темы слои перерисовываются.

У приложения нет доступа в интернет:
- сетевые разрешения, которые приносит MapLibre, удалены из манифеста;
- MapLibre переведена в режим «нет сети» (`MapLibre.setConnected(false)`), иначе без разрешения ACCESS_NETWORK_STATE она падала бы при открытии карты;
- проверку выполняет `./gradlew :app:verifyNoNetworkPermissions`, она же запускается перед каждой сборкой и установкой APK.

## Что проверить в поездке
- Карта открывается без сети (режим полёта) и без падения.
- Подписи улиц по-русски (поле `name:ru` в тайлах; иначе — местное название).
- Карта не тормозит при 2 Гц обновлений; нагрев.
- Круг неопределённости меняет цвет при смене режима.
- Камера не дёргается на стоянке.
- Атрибуция видна.
- Переключение вкладок во время записи:
  - камера переподключается, поэтому возможен разрыв кадров (порядка сотен миллисекунд);
  - на вкладке «Навигация» нет превью, поэтому стоит сверить разрешение анализа (`frameSize` в журнале) с вкладкой «Отладка».
- Иконки манёвров читаются на ходу; номер съезда с кольца.

## Известные ограничения
- **Только коридор.** Вне коридора ±500 м видны только обзорные масштабы (< 10).
- **Без склонений и полос** — как в M3a.
- **Без «О приложении».** Атрибуция есть только на карте; отдельного экрана пока нет.
- **Карта грузится при входе на вкладку**, а не по появлению файлов.
